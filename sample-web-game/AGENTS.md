# AGENTS.md

このディレクトリは、生徒がAI(Claude CodeやChatGPTなど)と一緒にWebゲームを作るためのサンプル・ひな形です。
AIコーディングエージェントがこのディレクトリ配下で作業するときは、このファイルの内容に従ってください。

## このプロジェクトについて

生徒が自分で考えたWebゲームをAIの力を借りて作り、「NESTON Games Hub」というポータルサイトに登録・公開することが目的です。
使うのは小学生・中学生・高校生なので、技術的な難しさよりも「自分で作った」「仕組みが分かる」ことを大切にします。

## 技術的なルール

- **素のHTML・CSS・JavaScriptだけ**で作る(React・Vueなどのフレームワークや、npm/ビルドツールは使わない)
- `index.html` を開くだけで動くこと(サーバーやビルド工程を必要としない)
- 外部ライブラリは、一般的によく使われているもの(例: Phaser、p5.js、GSAPなど)であればCDN経由で利用してよい。マイナーすぎるもの・出所が不明なものは避ける

## コードを書くときのルール

- 処理はシンプルで分かりやすい書き方を優先する。難しいテクニックや省略した書き方より、読んで理解できることを優先する
- まとまった処理の前には、**日本語でコメント**を入れる(あとで本人や先生がコードを見返したときに、「何のための処理か」がすぐ分かるようにするため)
- 変数名・関数名は内容が想像できる分かりやすい名前にする
- 1つのファイルが長くなりすぎないようにする(目安: `index.html` / `style.css` / `script.js` の3ファイル構成)

## 内容・表現のルール

- 作者は小学生・中学生・高校生であることを前提にする
- 暴力的・性的・差別的な表現、特定の個人や団体を傷つける表現、政治・宗教に関する偏った主張は禁止
- グロテスクな表現や、年齢的にふさわしくない言葉づかいも避ける
- 判断に迷う内容を生徒がリクエストしてきた場合は、そのまま実装せずに、より適切な表現に置き換えることを提案する

## 公開用の情報(game.json)

NESTON Games Hubに登録する際、以下の3つの情報が必要になります。ゲームが完成したら、このディレクトリ直下に `game.json` という名前で、次の形式のファイルを作成してください。

```json
{
  "title": "ゲームのタイトル",
  "author": "作者名(ニックネーム)",
  "thumbnail": "thumbnail.png"
}
```

- `title`: ゲームのタイトル
- `author`: 作者名。**本名ではなくニックネームを使うこと**(個人情報保護のため)
- `thumbnail`: サムネイル画像のファイル名(このディレクトリ直下に、横長(例: 480×360程度)の画像ファイルとして置く)

この3つの情報(サムネイル画像・タイトル・作者名)は、NESTON Games Hub上で誰でも見られる状態で公開されます。

## GitHubリポジトリ名のルール

このゲームをGitHubリポジトリとして公開するときは、リポジトリ名を次のルールで付けてください。

```
苗字(ローマ字)-名前の頭文字(アルファベット1文字)-アプリ名(英語・ケバブケース)
```

例: 「山田太郎」くんが「サイコロゲーム(dice game)」を作った場合

```
yamada-t-dice-game
```

- 苗字・名前はすべてローマ字・小文字にする
- 単語の区切りはハイフン( `-` )を使う
- アプリ名は内容が分かる英語の単語にする(日本語のローマ字そのままは避ける)
